# القرآن الكريم — المصحف الشريف | YKdev

> إصدار المشروع: **v7** (نسخة تصحيحية للخط والهوية والنصوص).

موقع مصحف عربي بواجهة تحريرية هادئة، بخلفية داكنة شبه سوداء، ولمسات زجاجية خفيفة، ولمسة ذهبية واحدة. يعرض صفحات مصحف المدينة كاملة (٦٠٤ صفحات) بالرسم العثماني، مع تلاوات متزامنة مع الكلمات، وفهرس صفحات، ووضع عرض كامل للصفحة. لا توجد ملفات MP3 محلية؛ الصوت يُبثّ من مصادره الخارجية عند الطلب.

## التشغيل محليًا

1. فك ضغط الحزمة.
2. افتح مجلد المشروع في الطرفية.
3. شغّل: `./start.sh`
4. افتح `http://localhost:8080`.

يجب فتح الموقع عبر خادم HTTP/HTTPS وليس `file://` حتى يتمكن المتصفح من قراءة ملفات JSON والضغط. لا يحتاج المشروع إلى Node.js أو npm أو قاعدة بيانات.

## النشر على نطاق عام

ارفع جميع محتويات مجلد المشروع إلى جذر الموقع على استضافة ملفات ثابتة، وفعّل HTTPS. لا تغيّر أسماء الملفات أو بنية المجلدات.

## التصميم

- خلفية `#08090a`، نص عاجي دافئ، ولمسة ذهبية `#e5cb92`.
- خطوط محلية داخل `assets/fonts/`: Readex Pro للواجهة، Amiri للعناوين، وNoto Naskh Arabic لنص المصحف. لا يعتمد الموقع على Google Fonts وقت التشغيل، ويعمل كل شيء دون إنترنت محلي.
- شعار مخصص `icons/logo.svg` يجمع هيئة المحراب والكتاب المفتوح، مع أيقونة تطبيق متناسقة `icons/favicon.svg`.
- أسطح زجاجية خفيفة (`backdrop-filter` محدود) بدل التأثيرات الثقيلة، وحركة هادئة تحترم `prefers-reduced-motion`.
- مظهر داكن افتراضي ومظهر فاتح كامل، مع حفظ الاختيار محليًا.
- تصميم متجاوب: فهرس السور درج على الهاتف، وشريط مشغل سفلي مضغوط، وصفحة مصحف تتكيف مع العرض.

## الوظائف

- نص القرآن المحلي: ١١٤ سورة و٦٢٣٦ آية.
- صفحات مصحف المدينة: ٦٠٤ صفحات، تُحمَّل بيانات الصفحة الحالية والتالية عند الحاجة وتُخزَّن في Cache Storage.
- عرض أسطر الصفحة كما في المصحف، مع فواصل السور والبسملة وعلامات نهاية الآيات.
- ١٢ قارئًا برواية حفص عن عاصم، لكل قارئ ١١٤ رابط سورة صوتية خارجية. عشرة قرّاء بتوقيت الكلمات.
- نافذة اختيار القرّاء: بطاقات زجاجية مقسّمة إلى «مع تزامن الكلمات» و«تلاوات كاملة».
- تظليل الكلمة النشطة أثناء التلاوة، والضغط على أي كلمة للانتقال إلى موضعها الصوتي عند توفر التوقيت.
- فهرس صفحات كامل مجمّع حسب الأجزاء الثلاثين، مع بحث برقم الصفحة.
- وضع المصحف الكامل: صفحة معزولة تملأ الشاشة، مع التنقل والتكبير وفهرس الصفحات وملء الشاشة.
- البحث في نص القرآن، المحفوظات، وحفظ آخر موضع قراءة محليًا.
- تكرار الصفحة على حدود كلماتها الفعلية عند توفر توقيت القارئ.
- تحميل صورة PNG للصفحة عند الطلب عبر `html2canvas` من jsDelivr.
- مشغّل سفلي: تشغيل/إيقاف، الآية السابقة والتالية، شريط التقدم، والتحكم في السرعة.
- تحميل ملف MP3 للسورة الحالية بصوت القارئ المختار؛ لا يضمّن الموقع الصوت داخله.
- صفحة `about.html` مستقلة تشرح الموقع ووظائفه وخصوصيته ومصادره، وتنسب التطوير إلى **YKdev** مع البريد `ykdev321@gmail.com`.

## الخصوصية

لا حسابات، ولا إعلانات، ولا أدوات تتبع. تُحفظ المحفوظات وآخر موضع قراءة والمظهر وحجم الخط في `localStorage` داخل المتصفح فقط. الصوت يُبثّ من روابط خارجية. نص القرآن وفهرس بدايات الصفحات مضمّنان محليًا، بينما تُحمّل تخطيطات الصفحات التفصيلية عند الحاجة وتُحفظ في Cache Storage.

## مصادر الأصول والترخيص

- **تخطيط الصفحات:** [Madinah Mushaf JSON](https://github.com/ouryhamdalaye/madinah-mushaf-json)، مرخص تحت CC BY-SA 4.0. يتطلب النسب للمصدر ومشاركة التعديلات على بيانات التخطيط بموجب الرخصة نفسها. تخطيط المستودع مشتق من `zonetecde/mushaf-layout`، ويذكر مستودع البيانات أن المصدر الأعلى لا يعلن ترخيصًا؛ تحقّق من هذه النقطة قبل الاستخدام التجاري أو إعادة توزيع بيانات التخطيط.
- **الخطوط:** Readex Pro وAmiri (للعناوين) نسخ محلية ضمن الحزمة وبموجب SIL Open Font License (OFL). خط Noto Naskh Arabic لنص المصحف يُحمّل من Google Fonts، وهو أيضًا بموجب SIL Open Font License 1.1؛ وتظل نسخة النظام بديلًا محليًا عند توافرها.
- **النص وفهرس القراء والتوقيتات:** من الملفات التي زوّد بها صاحب المشروع.
- **الصوت:** روابط بعيدة كما وردت في `data/reciters.json`؛ توافر الصوت وحقوق إعادة استخدام التسجيلات يحددهما كل مصدر صوتي.

## ملاحظات مهمة قبل النشر

1. **بيانات تخطيط الصفحات:** ملفات تخطيط صفحات المصحف وملف بدايات الصفحات تُحمّل من jsDelivr مع بديل raw.githubusercontent.com عند الحاجة، وليست مضمّنة بالكامل داخل الحزمة. يجب أن يكون لدى الزائر اتصال بالإنترنت عند أول فتح لكل صفحة؛ بعد نجاح التحميل يحتفظ المتصفح بالصفحة في Cache Storage. إن تعذّر المصدران، يعرض الموقع النص المحلي بتقسيم احتياطي بدل عرض صفحة مزيفة.
2. **تزامن الكلمات:** بيانات تخطيط المصحف توفر `word_index` يبدأ من صفر، وملفات التوقيت المرفقة تستخدم رقم الكلمة ابتداءً من واحد؛ يربط الموقع بينهما بإضافة 1. لا يمكن ضمان تشغيل كل خادم صوت خارجي أو ثبات جميع التسجيلات إلى الأبد.
3. **التغطية:** ملف توقيت رعد الكردي ينقصه توقيت أساسي لست آيات بحسب فحص بيانات الحزمة؛ ستظل القراءة متاحة، لكن لن يمكن تظليل أو تكرار مواضع تلك الآيات اعتمادًا على توقيت غير موجود.
4. **خط المصحف:** يحتاج Noto Naskh Arabic إلى اتصال عند أول تحميل من Google Fonts ما لم تكن نسخة الخط مثبتة على الجهاز. يحاول عامل الخدمة حفظ CSS وملفات WOFF2 بعد تحميلها بنجاح؛ وإذا تعذّر الاتصال ولم توجد نسخة نظام محلية، سيستخدم المتصفح خط serif بديلًا، ولذلك يُنصح بفتح الموقع مرة واحدة مع اتصال.
5. **صورة PNG:** تعتمد على تحميل `html2canvas` من jsDelivr عند الضغط على زر التحميل.
6. **الاختبار:** تم فحص بنية JavaScript وJSON، روابط الملفات المحلية، الأعداد الأساسية، سلامة أرشيف التوقيتات، وعدم وجود ملفات MP3 محلية. لم يُجرَ في هذه النسخة اختبار بصري على أجهزة متعددة داخل بيئة البناء؛ لذلك يُنصح بمراجعة العرض النهائي على الهاتف والحاسوب بعد النشر. لا يمكن ضمان توافر خدمات الطرف الثالث مستقبلًا؛ اختبر الموقع بعد نشره على النطاق الفعلي قبل الإعلان عنه.

## فحص المشروع قبل النشر

شغّل `./verify.sh` من داخل مجلد المشروع. يتحقق السكريبت من صياغة JavaScript، وبيانات القرآن والقراء وروابط الصوت، وفك وفحص أرشيفات توقيت الكلمات والآيات، وروابط الصفحات المحلية، وعدم تكرار معرّفات HTML، وإعداد الخط وتكبيره، ووجود رابط «عن الموقع»، وفحص CSS والخطوط المحلية. يتطلب Python 3؛ ويجري فحص JavaScript إذا كان Node.js مثبتًا. للمقارنة الاختيارية مع حزمة سابقة، عيّن المتغير `MISHKAT_BASELINE_ZIP` إلى مسار ZIP القديم قبل تشغيل السكريبت.
